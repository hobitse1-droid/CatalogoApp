#  CatalogoApp  
Aplicación de escritorio desarrollada en **C# (.NET)** para gestionar un **catálogo de productos** de forma sencilla, rápida y organizada.  
Permite registrar, editar, eliminar y visualizar elementos dentro de un catálogo dinámico.

---

##  Características principales
-  **Agregar** nuevos elementos al catálogo  
-  **Editar** información existente  
-  **Eliminar** registros  
-  **Visualizar** la lista completa de productos  
-  Persistencia de datos (según implementación)  
-  Interfaz intuitiva y fácil de usar
